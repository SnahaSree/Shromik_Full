# SHROMIK

> বিশ্বস্ত নিয়োগ, মর্যাদার মজুর

SHROMIK is a Bangladesh-focused construction workforce platform that connects verified construction workers with contractors and employers.

## Project Status

🚧 Under active development

## Vision

To build a trusted digital workforce ecosystem for Bangladesh's construction industry.

## Core Platform

- Verified construction workers
- Contractor workforce discovery
- Job marketplace
- Project management
- Attendance
- Payments
- Invoices
- Ratings
- Training
- Safety
- Notifications
- AI assistant
- Administrative management

## Technology

### Frontend
